# Реализованные решения видеоканала Wi-Fi HaLow (на 08.10.2026, релиз)

Стенд: две платы LilyGO T-Halow (ESP32-S3 + модуль TX-AH-R900P), камера OV5640.
Цифры — из журнала `docs/halow_link_debug.md`; прогоны по 4–10 мин, разброс
между одинаковыми прогонами до ±20 %. Строки 1–31 — состояние на 29.09, 32–51 —
добавлено к релизу 08.10 (`checkpoints/release_2026-10-08/README.md`).

**Итог релиза на 5 м:** 1063 кбит/с полезного видео, 5 к/с, 480×320, потеряно 1,4 %
кадров, мощность передатчика 1 дБм.

## Что показывает PER модуля

`per=` в строке `tx1` — доля неудачных **попыток** передачи к приёмнику, а не потерянных
данных: каждый повтор и каждая проба модуляции — отдельная попытка, а пачка (A-MPDU), на
которую камера не услышала Block-ACK, считается неудачной целиком, даже если данные дошли.
Служебные кадры PER не завышают: по всем кадрам модуля PER 54 %, только к приёмнику — 60 %
(07.10). Что видит пользователь — потери кадров в просмотрщике: 0,5–4 % на 5 м (релиз 1,4 %). Подробно —
`docs/halow_link_debug.md`, раздел «08.10: что считает PER».

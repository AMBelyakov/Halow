Цель и задачи

Цель — исследовать эффективность Wi-Fi HaLow для передачи данных с удалённых объектов в реальных условиях на платформе LilyGO T-HaLow.

  1. Выявить задачи БПЛА, не решаемые существующими каналами; сравнить Wi-Fi HaLow с IEEE 802.11 и LoRa
  2. Обосновать эксперимент, разработать программу и методику, выбрать и настроить средства
  3. Провести эксперименты и сравнить с IEEE 802.11 на идентичной платформе
  4. Выполнить экономическое обоснование и анализ условий труда
  5. Сформулировать предложения по интеграции в существующие модели БПЛА

Какой канал связи нужен БПЛА

Нацпроект «Беспилотные авиационные системы» (2024–2030): мониторинг ЛЭП, поиск людей, обследование объектов. Каналу связи с БПЛА нужны:

Дальность

сотни метров — километры, в том числе за препятствиями

Скорость

для видео: сотни кбит/с — единицы Мбит/с

Надёжность

малые потери и задержка

Свободный диапазон

без разрешения на частоты, по нормам ГКРЧ

Wi-Fi 2,4 ГГц

скорость есть, дальности нет

LoRa

дальность есть, скорости нет

Wi-Fi HaLow (868 МГц)

может закрыть все четыре, но реальные платы почти не измерены

2

Беспилотникам по нацпроекту — мониторинг ЛЭП, поиск людей, обследование объектов — нужен канал связи с четырьмя свойствами: дальность до километров, скорость для видео, надёжность и свободный диапазон без разрешения на частоты. Wi-Fi 2,4 гигагерца даёт скорость, но не дальность; LoRa — дальность, но не скорость. Wi-Fi HaLow может закрыть все четыре, но реальные характеристики доступных плат почти не измерены.

Какой канал связи нужен БПЛА

Для решения задач, поставленных в рамках национального проекта «Беспилотные авиационные системы» (2024–2030), — мониторинга линий электропередачи, поиска людей, обследования объектов — необходимо спроектировать канал связи с БПЛА, отвечающий следующим параметрам:

Дальность

сотни метров — километры, в том числе за деревьями и строениями

Скорость

достаточная для видео с борта: от сотен килобит до единиц мегабит в секунду

Надёжность

малые потери видеокадров и задержка, устойчивость к провалам сигнала

Свободный диапазон

полоса, которую можно использовать без разрешения на частоты и регистрации передатчика, — достаточно соблюдать нормы ГКРЧ

Готовые варианты закрывают эти параметры лишь частично:

Wi-Fi 2,4 ГГц

скорость есть, но дальность — сотни метров, препятствия гасят сигнал сильнее

LoRa

дальность есть, но только телеметрия — единицы кбит/с, видео не передать

Wi-Fi HaLow (IEEE 802.11ah, 868 МГц)

может закрыть все четыре параметра, но реальные характеристики доступных плат почти не измерены

Wi-Fi HaLow для БПЛА · 2 / 16

Для решения задач национального проекта «Беспилотные авиационные системы» — мониторинга линий электропередачи, поиска людей, обследования объектов — нужен канал связи с беспилотником с четырьмя свойствами. Дальность — сотни метров и километры, в том числе за препятствиями. Скорость, достаточная для видео, — от сотен килобит до единиц мегабит в секунду. Надёжность — малые потери и задержка. И свободный диапазон — полоса, которой можно пользоваться без разрешения на частоты и регистрации передатчика, достаточно соблюдать нормы ГКРЧ. Готовые варианты закрывают это лишь частично: у Wi-Fi 2,4 гигагерца есть скорость, но не дальность; у LoRa есть дальность, но не скорость. Wi-Fi HaLow может закрыть все четыре параметра, но реальные характеристики доступных плат почти не измерены — паспортные данные сняты в идеальных условиях.

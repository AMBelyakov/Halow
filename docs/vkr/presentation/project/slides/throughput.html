Пропускная способность платформы: 121 → 708 кбит/с

Каждый шаг — найденное и устранённое узкое место: драйвер UART модуля, паузы между пакетами, опрос приёма в цикле передачи.

Wi-Fi HaLow для БПЛА · 10 / 17

Исходно платформа давала 121 кбит/с — на два порядка меньше, чем позволяет радиоканал. Последовательный поиск ограничивающих звеньев поднял скорость почти в шесть раз. Самый крупный шаг — драйвер UART модуля: он читал один байт за прерывание, и при 3 Мбод 89,5 % байтов терялись на переполнении. Изменение драйвера устранило переполнения полностью.

Часть кадров приходила с радугой: в потоке с камеры терялся один байт. Долго искали причину в шлейфе и тактировании. Опыт, где менялась только мощность передатчика, дал ответ: при 1 дБм повреждений ноль, при 20 дБм — 44 процента. Это наводка антенны на шлейф камеры в нескольких сантиметрах. Разработано программное исправление без порогов, проверенное на 30 сохранённых кадрах по независимой метрике; на стенде оно почти вдвое увеличивает число целых кадров.

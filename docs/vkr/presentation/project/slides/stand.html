5

Программа на компьютере восстанавливает пропавшие фрагменты, показывает видео и пишет журнал показателей канала.

Wi-Fi HaLow для БПЛА · 8 / 16

Стенд — две одинаковые платы LilyGO T-HaLow; из доступных в России вариантов это самый дешёвый законченный узел. Путь видео такой. Камера снимает кадр 480 на 320 и по шине DVP отдаёт его процессору. Процессор сжимает кадр в JPEG на двух ядрах, режет на нумерованные фрагменты до 1400 байт, добавляет контрольные фрагменты и по UART отдаёт радиомодулю. Модуль камеры работает точкой доступа и передаёт фрагменты по Wi-Fi HaLow в канале шириной 2 мегагерца с центральной частотой 867 мегагерц, не более 14 дБм. Модуль приёмника — станция; он отдаёт фрагменты процессору приёмника, тот передаёт их по USB в компьютер и отвечает камере квитанцией. Программа на компьютере восстанавливает пропавшие фрагменты, показывает видео и пишет журнал.

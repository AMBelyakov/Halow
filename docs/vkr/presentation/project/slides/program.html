Wi-Fi HaLow для БПЛА · 8 / 17

Программа — три этапа. Первый, стендовый, выполнен: сначала на столе, с 28 сентября — на трассе 5 метров через стену в разрешённом канале. Дальность и сравнение с Wi-Fi 2,4 ГГц и LoRa по согласованию с руководителем выполняются по расчёту и опубликованным натурным данным других авторов. Методическое правило: канал на 5 метрах меняется в разы по времени суток, поэтому сравниваемые варианты чередуются внутри одного включения питания.

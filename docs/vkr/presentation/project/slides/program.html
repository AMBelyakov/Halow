Wi-Fi HaLow для БПЛА · 9 / 16

Программа — три этапа, у каждого своя цель. Стендовый этап — найти, что ограничивает скорость и надёжность, и проверить каждую доработку опытом «выключено — включено»; сначала в помещении до 5 метров, затем на трассе 5 метров через стену в разрешённом канале. Второй этап — дальность: на трассе прямой видимости определить, где пропадают видео и связь у Wi-Fi HaLow и Wi-Fi 2,4 гигагерца одной пары плат; влияние высоты антенн — расчётом. Третий — сравнение с другими технологиями по критериям задания. Методическое правило: канал меняется в 2–3 раза по времени суток, поэтому сравниваемые варианты чередуются в одном включении питания.

Предложения по интеграции в БПЛА

SPI или SDIO вместо UART

через UART полезная скорость не превысит 3,94 Мбит/с

Аппаратное сжатие

программный JPEG на ESP32-S3 ограничивает поток ~0,8 Мбит/с

Антенна вдали от камеры

наводка 20 дБм повреждала до 44 % кадров; экранировать шлейф

Мощность по уровню сигнала

потолок 14 дБм; снимает перегрузку при взлёте и посадке

Исправление кадров

программная страховка: почти вдвое больше целых кадров

Канал 1–2 МГц

в полосе 866–868 МГц, по требованиям к устройствам малого радиуса действия

Шесть предложений для интеграции в существующие модели БПЛА, каждое следует из измерений: интерфейс SPI или SDIO вместо UART; аппаратное сжатие; разнос антенны и камеры с экранированием шлейфа; регулировка мощности по уровню сигнала с потолком 14 дБм, которая снимает перегрузку приёмника при взлёте и посадке; программное исправление кадров как страховка; канал 1–2 МГц в разрешённой полосе.
